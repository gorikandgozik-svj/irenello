# SKERRY Engine 0.28

SDK для браузера. Раздел native содержит отдельный проект Godot с физикой Jolt. Стенды Foundry и Elevation используют общий SkerrySDK.js. Внешние библиотеки для запуска этих HTML не нужны. Для работы требуется WebGL.

## Запуск и собственный проект

Откройте Skerry.html для лаборатории транспорта и планеты. Чтобы запустить турбинный стенд, откройте examples/foundry/index.html в браузере. Потяните изображение для вращения камеры, смените профиль или вырежьте часть кладки. В examples/elevation/index.html находится стенд потоковой загрузки высот. Регион Jacksboro встроен в пример и доступен офлайн.

Для нового проекта из корня архива выполните:

    python skerry.py new my_project --template empty
    python skerry.py build my_project MyProject.html

Вместо empty можно выбрать foundry, elevation или landscape. В каталоге проекта редактируйте main.js и index.html. После изменения модулей в src выполните python build.py для обновления SDK.

## Что добавлено

- Game.setProfile управляет разрешением, тенью, детализацией процедурной местности и выбором пути освещения. Mobile использует прямой проход, AA и Ultra поддерживают отложенный проход для непрозрачных объектов. Отражения SSR и непрямое освещение Ultra используют экранные данные. Точечные источники распределяются по экранным плиткам, до 32 на плитку. Статистика tileOverflow показывает отсечённые назначения.
- VoxelVolume хранит номера материалов. brush принимает пользовательскую функцию редактирования. carve вырезает сферу. flush обновляет затронутые чанки и их коллайдеры. При завершении работы вызовите dispose для тома и потока высот перед Game.dispose.
- ElevationAtlas.open загружает заголовок локального файла, читает тайлы высот по требованию, сохраняет родительский меш до готовности дочерних. tools/elevation_pack.py создаёт пирамиду высот. TerrariumAtlas реализует загрузку отдельного географического региона через XYZ. Проверены декодирование и переход через 180° с локальными тестовыми данными. Сквозная сетевая загрузка не проверена.
- В native добавлена конечно-разностная модель волн. Для проверки нативного стенда откройте native/project.godot в Godot либо выполните из native команды godot --headless --editor --import и godot --headless --fixed-fps 120 -- --verify.

## Проверка

В qa находятся результаты тестов и замеров. Кадры записаны из команд StageRenderer и воспроизведены на Mesa GLES llvmpipe. Время включает исполнение команд и ожидание завершения драйвера. Для каждого профиля первый кадр исключён из медианы. Это измерение воспроизведения на CPU, а не времени интерактивного кадра на целевой видеокарте.

| Профиль | Разрешение | Треугольники основного прохода | Медиана трёх кадров |
|---|---|---:|---:|
| Mobile | 1280×720 | 14568 | 63,5 мс |
| AA | 1920×1080 | 19036 | 213,3 мс |
| Ultra | 3840×2160 | 35336 | 1024,7 мс |

Воспроизведение из корня проекта требует Node.js, Python, Pillow и EGL/GLES Mesa:

    node tools/capture/record.cjs /tmp/foundry --foundry
    python tools/capture/replay.py /tmp/foundry
    node tests/engine28.cjs

## Статус

Предрелиз для разработки и тестирования. 4K/60 FPS и целевые миллионы треугольников на аппаратных устройствах не подтверждены. Аппаратные RT, mesh shaders, bindless, DLSS, XeSS и генерация кадров в SDK отсутствуют. Планетарная база снимков и зданий, иерархия городов до интерьеров и полноценная симуляция деформируемых автомобилей остаются открытыми требованиями. Отдельный нативный проект использует возможности Godot. Браузерный SDK написан на JavaScript. Описание предыдущих версий находится в README_027_RU.md и более ранних файлах.
