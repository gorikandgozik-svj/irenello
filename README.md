# SKERRY Engine 0.29

Предрелиз SDK для браузера с отдельным нативным стендом Godot/Jolt. Для запуска откройте examples/foundry/index.html, examples/elevation/index.html или examples/geometry/index.html в браузере с WebGL. Исходный код двигателя находится в src. Описание SDK и формата примеров — в README_028_RU.md.

## Свой проект

    python skerry.py new mygame --template empty
    python skerry.py build mygame MyGame.html

Для воспроизведения испытаний вместо empty укажите geometry, elevation либо foundry. После редактирования SDK запустите python build.py. Проект в native открывается через Godot. Выполните тесты SDK из корня проекта:

    for t in tests/*.cjs; do node "$t" || exit 1; done

## Что изменилось

Текстуры списков источников освещения теперь переиспользуются, пока камера и свет не изменились. При перемещении источника, изменении его цвета или размера кадра списки автоматически обновляются. Непрозрачные поля инстансов поддерживают отложенный путь. Поток высот переиспользует план тайлов при неподвижной камере. При закрытии Game связанные воксельные тома и потоки высот освобождаются автоматически.

Импортёр glTF проверяет типы атрибутов, согласованность длины и конечность значений. Для одного импортируемого файла установлен предел 128 МиБ и бюджет 16 777 216 декодированных скалярных значений. Для Terrarium проверяются координаты тайла и размер декодированных данных. Эти проверки охватывают отдельные классы ошибок.

## Замеры и повторение

Результаты в qa/029. Инстансинг выводит 2048 копий одного процедурного меша в одном основном draw call. Бюджет указывает число переданных треугольников до растеризации. Это синтетическая сцена. На llvmpipe трёхмерный драйвер работает на процессоре. Время в load-timing.log включает первый кадр профиля и ожидание завершения команд. В foundry-timing.log первый кадр каждого профиля прогревочный. Показатели стенда нельзя переносить на конкретный телефон или GPU.

    node tools/capture/record.cjs /tmp/dem --elevation
    python tools/capture/replay.py /tmp/dem
    node tools/capture/record.cjs /tmp/stress --geometry
    python tools/capture/replay.py /tmp/stress

Захват требует EGL/GLES, Mesa, Python и Pillow. 4K-кадр рельефа доступен в qa/029/earth-4k.jpg. Информация о происхождении ассетов приведена в assets/Environment-LICENSE.txt и описаниях предыдущих сборок.
