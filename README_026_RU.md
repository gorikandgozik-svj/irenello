# SKERRY 0.26

Откройте Skerry.html для автодрома, полёта, ходьбы, мастерской и теста геометрии. Файл автономный. В режиме «Тест геометрии» выберите 16, 128, 256 или 512 экземпляров. Для сравнения устройств вручную установите «4K экран» и дождитесь обновления счётчика. Счётчик показывает среднее время вывода кадров. Кнопка «Фото 6K» рендерит изображение частями.

Для города распакуйте архив и откройте native/project.godot в Godot 4.7.2. Нажмите F6 в сцене City или F5 для запуска проекта. W/S управляют газом и тормозом, A/D рулём. Tab включает обзорную камеру, R возвращает машину на старт. Барьер стоит в 28 метрах впереди. На Forward+ клавиша F переключает нативное разрешение и FSR 2 с внутренним масштабом 67%. В этом выпуске браузерная и нативная сцены имеют общую модель болида и разные системы исполнения.

## Воспроизведение

В корне проекта выполните python build.py для пересборки HTML и SDK. Семь проверок лежат в tests и запускаются командой node для каждого файла .cjs. В native команда godot --headless --editor --import готовит ассеты, затем godot --headless --fixed-fps 120 -- --verify выполняет заезд на 1500 физических шагов. Генератор native/tools/bake.cpp собирается с -std=c++20 и запускается из native.

Запись вызовов WebGL выполняет node tools/capture/record.cjs /tmp/skerry-frame. Добавьте --stress для трёх нагрузочных кадров. python tools/capture/replay.py /tmp/skerry-frame воспроизводит вызовы через EGL/GLES, считывает пиксели и измеряет интервал между синхронизациями драйвера. Измерения включают накладные расходы воспроизведения. Журналы лежат в screenshots. README_025_RU.md описывает режимы предыдущей версии.
